# How to track Booking.com hotel prices with Python

## Introduction
Tracking hotel prices automatically can save travelers hours of manual checking and give businesses real‑time market insight. By building a lightweight Python service you gain visibility into pricing fluctuations, enable dynamic re‑pricing strategies, and automate alerts when a desired price point is reached. The solution respects rate limits, stores historic data, and stays flexible enough to adapt to changes in the target website.

## Why This Matters
Software engineers often need up‑to‑date pricing information for:

* **Dynamic pricing tools** that adjust offers based on competitor moves.  
* **Travel agents** who must present the best available rate to clients.  
* **Price‑comparison platforms** that aggregate data from multiple suppliers.  

A self‑hosted tracker eliminates reliance on third‑party APIs, reduces latency, and keeps the data pipeline under your control. It also provides a sandbox for experimenting with web‑scraping techniques, rate‑limit handling, and data‑persistence patterns that are transferable to other domains.

## How It Works
The system runs on a simple scheduler that periodically fetches the hotel page, parses the price, persists it to a local SQLite database, and compares the new value with the previous entry. If a change is detected, an optional notification (email, webhook, or console log) is emitted.

```mermaid
flowchart TD
    A[Scheduler (APScheduler)] --> B[Fetch Booking.com page]
    B --> C[Parse HTML (BeautifulSoup)]
    C --> D[Extract price, currency, room type]
    D --> E[Store in SQLite (SQLAlchemy)]
    E --> F[Load latest record]
    F --> G{Price changed?}
    G -->|Yes| H[Trigger alert (log/webhook)]
    G -->|No| I[Wait for next run]
    A --> I
```

Key components:

* **Scheduler** – `APScheduler` drives the crawl at configurable intervals (e.g., every hour).  
* **HTTP client** – `requests` with a realistic User‑Agent to mimic a browser.  
* **Parser** – `BeautifulSoup` extracts the price element identified via data attributes.  
* **Persistence** – SQLAlchemy creates a `price_history` table and handles transactions.  
* **Comparison** – The latest row is fetched and compared; a delta triggers a notification.

## Core Concepts
* **Configuration** – URL, check‑in/out dates, request headers, and scheduler interval are stored in a `.env` file to keep secrets out of code.  
* **Database model** – `PriceRecord` holds `scraped_at`, `price`, `currency`, and `room_type`. The table is created automatically on first run.  
* **Error handling** – Network failures, parsing errors, and database constraints are logged and do not crash the scheduler.  
* **Selectors** – Booking.com frequently updates its DOM; the scraper uses data‑test attributes (`data-test="price"`) that are stable across minor redesigns.  
* **Extensibility** – New hotels, date ranges, or alert destinations can be added by subclassing `PriceTracker`.

```python
# src/price_tracker/scrapers/booking.py
import re
import logging
from typing import Optional, Dict
import requests
from bs4 import BeautifulSoup

logger = logging.getLogger(__name__)

def fetch_page(url: str, headers: Dict[str, str]) -> Optional[BeautifulSoup]:
    """Return a BeautifulSoup object or None on failure."""
    try:
        resp = requests.get(url, headers=headers, timeout=10)
        resp.raise_for_status()
        return BeautifulSoup(resp.text, "html.parser")
    except Exception as exc:               # custom handling
        logger.error(f"[ERROR] Failed to fetch {url}: {exc}")
        return None

def extract_price(soup: BeautifulSoup) -> Optional[Dict[str, str]]:
    """Pull price & related metadata from the parsed page."""
    # Booking.com typically uses data-test="price" for the main price block
    price_tag = soup.select_one("span[data-test='price']")
    if not price_tag:
        logger.warning("Could not locate price element")
        return None

    raw = price_tag.get_text(strip=True)
    # Remove any non‑numeric characters except dot and comma
    cleaned = re.sub(r"[^0-9.,]", "", raw)
    # Convert European‑style commas to dots if needed
    numeric = cleaned.replace(",", ".")
    try:
        price_value = float(numeric)
    except ValueError:
        logger.warning(f"Unable to parse price text: {raw}")
        return None

    # Infer currency from an adjacent label if present
    currency = "EUR"  # safe default; refine based on real page structure
    label = price_tag.find_previous("span", attrs={"data-test": "price-currency"})
    if label:
        currency = label.get_text(strip=True)

    # Heuristic room type – look for a heading containing the word "Room"
    room_type = ""
    heading = soup.find("h2", text=lambda t: t and "Room" in t)
    if heading:
        room_type = heading.get_text(strip=True)

    return {
        "price": price_value,
        "currency": currency,
        "room_type": room_type,
    }
```

```python
# src/price_tracker/tracker.py
import logging
from datetime import datetime
from sqlalchemy import desc
from .models import Base, PriceRecord, Session, engine
from .scrapers.booking import fetch_page, extract_price

logger = logging.getLogger(__name__)

class PriceTracker:
    def __init__(self, url: str, check_in: str, check_out: str, headers: dict):
        self.url = url
        self.check_in = check_in
        self.check_out = check_out
        self.headers = headers
        # Ensure tables exist
        Base.metadata.create_all(engine)
        self.session_factory = Session

    def run(self) -> None:
        """Execute a single tracking cycle."""
        logger.info("Starting tracking cycle")
        soup = fetch_page(self.url, self.headers)
        if not soup:
            logger.error("Aborting cycle – page fetch failed")
            return

        data = extract_price(soup)
        if not data:
            logger.error("Aborting cycle – price extraction failed")
            return

        self._store_price(data)
        self._compare_and_alert(data)

    def _store_price(self, data: dict) -> None:
        with self.session_factory() as session:
            record = PriceRecord(
                price=data["price"],
                currency=data["currency"],
                room_type=data.get("room_type"),
            )
            session.add(record)
            session.commit()
            logger.info(f"Stored price {data['price']} {data['currency']}")

    def _compare_and_alert(self, new_data: dict) -> None:
        with self.session_factory() as session:
            latest = (
                session.query(PriceRecord)
                .order_by(desc(PriceRecord.scraped_at))
                .first()
            )
            if latest and abs(latest.price - new_data["price"]) > 0.01:
                msg = (
                    f"Price change detected!\n"
                    f"Previous: {latest.price} {latest.currency}\n"
                    f"New: {new_data['price']} {new_data['currency']}\n"
                    f"Room: {new_data.get('room_type')}\n"
                    f"Time: {datetime.utcnow().isoformat()}"
                )
                logger.warning(msg)
                self._send_alert(msg)
            else:
                logger.info("No significant price change")
```

### `src/price_tracker/__main__.py`
```python
# src/price_tracker/__main__.py
import logging
from apscheduler.schedulers.background import BackgroundScheduler
from .config import Settings
from .tracker import PriceTracker

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s - %(name)s - %(levelname)s - %(message)s",
)

def job():
    tracker = PriceTracker(
        url=Settings.HOTEL_URL,
        check_in=Settings.CHECK_IN,
        check_out=Settings.CHECK_OUT,
        headers={"User-Agent": Settings.USER_AGENT},
    )
    tracker.run()

if __name__ == "__main__":
    Settings.validate()
    scheduler = BackgroundScheduler()
    scheduler.add_job(job, "interval", minutes=Settings.SCHEDULER_INTERVAL_MINUTES)
    scheduler.start()
    try:
        # Keep the script alive
        while True:
            import time
            time.sleep(1)
    except (KeyboardInterrupt, SystemExit):
        scheduler.shutdown()
```

## Best Practices
* **Respect `robots.txt` and ToS** – Limit request frequency, honour `Crawl‑Delay`, and avoid heavy‑load patterns.  
* **Rotate User‑Agents and use proxies** – Reduces the chance of being blocked.  
* **Store headers and session cookies** – If Booking.com starts using client‑side rendering, a `requests.Session` can retain cookies across retries.  
* **Implement exponential backoff** – Retry failed fetches with increasing delays.  
* **Log to structured formats** – JSON‑line logs make downstream analysis easier.  
* **Use environment variables** – Never hard‑code credentials or URLs.  
* **Index the DB** – The `scraped_at` column is already indexed; adding a composite index on (`room_type`, `scraped_at`) can speed up reports.  

## Common Mistakes & Anti‑Patterns
