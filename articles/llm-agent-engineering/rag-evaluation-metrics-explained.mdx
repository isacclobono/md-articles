# RAG evaluation metrics explained

## Introduction

The Retrieval-Augmented Generation (RAG) architecture has become the de facto standard for grounding large language models in proprietary knowledge. Yet, I've watched too many teams deploy RAG systems that produce fluent, confident, and completely wrong answers. The root cause is almost always the same: they're evaluating the system like a chatbot instead of a retrieval system with a language model attached.

Traditional LLM benchmarks measure token prediction accuracy on curated datasets. Production RAG systems face a different reality: they must retrieve relevant documents from noisy, evolving corpora, then synthesize accurate answers from potentially conflicting information. These are fundamentally different evaluation challenges.

This article breaks down the three-dimensional evaluation framework that production RAG systems actually require: retrieval quality, generation quality, and end-to-end performance. We'll cover the metrics that matter, when to use them, and how to implement them in code.

## Why This Matters

Your RAG system is only as good as its weakest link. A perfect retrieval component that returns irrelevant documents is useless. Flawless document ranking means nothing if the language model hallucinates unsupported claims. Even balanced metrics can mask critical failures when users receive answers that sound authoritative but contradict the source material.

I've seen this failure mode cost real money. A financial services client built a RAG system for regulatory compliance queries. Their evaluation showed 92% similarity to reference answers using BLEU score. But when auditors checked, 40% of the generated responses contained factual errors not present in the retrieved documents. The system was optimizing for the wrong metrics.

Production RAG evaluation matters because:
- **User trust erodes quickly** when answers contradict source documents
- **Silent failures** are worse than obvious errors because they go undetected
- **Retrieval and generation errors compound** - poor retrieval makes generation impossible to evaluate correctly
- **Business outcomes depend** on factual accuracy, not just linguistic fluency

## How It Works

The RAG evaluation workflow operates as a continuous feedback loop. When a user submits a query, the system first retrieves relevant documents, ranks them, and passes the top-K results to the generation component. The generated response then flows through a comprehensive evaluation pipeline that measures quality across three dimensions.

The evaluation pipeline doesn't just measure quality—it creates an optimization loop. Each evaluation cycle generates insights that feed back into retrieval and generation improvements. This creates a system that gets smarter over time rather than degrading as the knowledge base evolves.

## Core Concepts

### The Three-Dimensional Evaluation Framework

**Retrieval Quality** measures how effectively the system finds relevant documents. This is the foundation—poor retrieval makes generation evaluation meaningless.

**Generation Quality** assesses the language model's output against ground truth, checking for factual consistency, linguistic quality, and answer completeness.

**End-to-End Performance** evaluates the complete system from user perspective: Does the answer actually help? Is it faithful to the source? Is it concise and actionable?

### Ground Truth Challenges

The fundamental challenge in RAG evaluation is establishing reliable ground truth. Unlike classification tasks with clear labels, RAG answers are often subjective, multi-faceted, and context-dependent. We need multiple evaluation strategies:

- **Human evaluation** for nuanced judgments
- **Automated metrics** for scale and consistency  
- **LLM-as-judge** for balancing human insight with automation

### Static vs Dynamic Evaluation

Static evaluation uses fixed test sets with predetermined answers. Dynamic evaluation continuously assesses production traffic. Both are necessary—static provides controlled benchmarking, while dynamic catches real-world degradation patterns.

### Custom MRR Implementation with Chunk-Level Relevance

```python
import numpy as np
from typing import List, Dict, Tuple, Set
import math

class RetrievalEvaluator:
    """Evaluates retrieval quality with chunk-level relevance scoring."""
    
    def __init__(self, relevance_threshold: float = 0.7):
        self.relevance_threshold = relevance_threshold
    
    def precision_at_k(self, retrieved_chunks: List[str], 
                      relevant_chunks: Set[str], k: int) -> float:
        """Calculate Precision@K - proportion of retrieved chunks that are relevant."""
        if k == 0 or not retrieved_chunks:
            return 0.0
        
        top_k = retrieved_chunks[:k]
        relevant_retrieved = sum(1 for chunk in top_k 
                               if self._is_relevant(chunk, relevant_chunks))
        return relevant_retrieved / min(k, len(retrieved_chunks))
    
    def recall_at_k(self, retrieved_chunks: List[str], 
                   relevant_chunks: Set[str], k: int) -> float:
        """Calculate Recall@K - proportion of relevant chunks that were retrieved."""
        if not relevant_chunks:
            return 0.0
        
        top_k = retrieved_chunks[:k]
        relevant_retrieved = sum(1 for chunk in top_k 
                               if self._is_relevant(chunk, relevant_chunks))
        return relevant_retrieved / len(relevant_chunks)
    
    def mean_reciprocal_rank(self, retrieved_chunks: List[str], 
                            relevant_chunks: Set[str]) -> float:
        """Calculate MRR - average of reciprocal ranks of first relevant document."""
        for i, chunk in enumerate(retrieved_chunks):
            if self._is_relevant(chunk, relevant_chunks):
                return 1.0 / (i + 1)
        return 0.0
    
    def ndcg_at_k(self, retrieved_chunks: List[str], 
                 chunk_relevance: Dict[str, float], k: int) -> float:
        """Calculate Normalized Discounted Cumulative Gain@K."""
        if not retrieved_chunks or k == 0:
            return 0.0
        
        # Calculate DCG for retrieved documents
        dcg = 0.0
        for i, chunk in enumerate(retrieved_chunks[:k]):
            relevance = chunk_relevance.get(chunk, 0.0)
            dcg += relevance / math.log2(i + 2)  # i+2 because log2(1)=0
        
        # Calculate ideal DCG (best possible ranking)
        ideal_relevances = sorted(chunk_relevance.values(), reverse=True)[:k]
        ideal_dcg = 0.0
        for i, relevance in enumerate(ideal_relevances):
            ideal_dcg += relevance / math.log2(i + 2)
        
        return dcg / ideal_dcg if ideal_dcg > 0 else 0.0
    
    def _is_relevant(self, chunk: str, relevant_chunks: Set[str]) -> bool:
        """Determine if a chunk meets relevance threshold."""
        # In production, this would use semantic similarity
        # For this example, we use exact matching with threshold
        return chunk in relevant_chunks
    
    def evaluate_retrieval(self, query_results: List[Tuple[str, List[str]]], 
                          ground_truth: Dict[str, Set[str]]) -> Dict[str, float]:
        """Comprehensive retrieval evaluation across multiple queries."""
        metrics = {
            'precision@5': [],
            'precision@10': [],
            'recall@5': [],
            'recall@10': [],
            'mrr': [],
            'ndcg@10': []
        }
        
        for query, retrieved_chunks in query_results:
            relevant = ground_truth.get(query, set())
            
            metrics['precision@5'].append(
                self.precision_at_k(retrieved_chunks, relevant, 5))
            metrics['precision@10'].append(
                self.precision_at_k(retrieved_chunks, relevant, 10))
            metrics['recall@5'].append(
                self.recall_at_k(retrieved_chunks, relevant, 5))
            metrics['recall@10'].append(
                self.recall_at_k(retrieved_chunks, relevant, 10))
            metrics['mrr'].append(
                self.mean_reciprocal_rank(retrieved_chunks, relevant))
            
            # For nDCG, we'd need relevance scores per chunk
            # This is a simplified version
            chunk_relevance = {chunk: 1.0 if chunk in relevant else 0.0 
                             for chunk in retrieved_chunks}
            metrics['ndcg@10'].append(
                self.ndcg_at_k(retrieved_chunks, chunk_relevance, 10))
        
        # Calculate averages
        return {metric: np.mean(values) for metric, values in metrics.items()}
```

### Multi-Dimensional Generation Evaluation Framework

```python
import re
from typing import List, Dict, Any, Optional
import torch
from transformers import pipeline, AutoTokenizer, AutoModelForSequenceClassification

class GenerationEvaluator:
    """Evaluates generation quality using lexical, semantic, and factual metrics."""
    
    def __init__(self, use_semantic_metrics: bool = True):
        self.use_semantic = use_semantic_metrics
        self._initialize_models()
    
    def _initialize_models(self):
        """Initialize evaluation models with lazy loading."""
        self.factuality_model = None
        self.similarity_model = None
        
        if self.use_semantic:
            try:
                # Lightweight factual consistency model
                self.factuality_model = pipeline(
                    "text-classification",
                    model="facebook/bart-large-mnli",
                    device=0 if torch.cuda.is_available() else -1
                )
            except Exception as e:
                print(f"Warning: Could not load factuality model: {e}")
    
    def rouge_scores(self, reference: str, candidate: str) -> Dict[str, float]:
        """Calculate ROUGE metrics with n-gram overlap."""
        def get_ngrams(text: str, n: int) -> List[str]:
            words = text.lower().split()
            return [' '.join(words[i:i+n]) for i in range(len(words)-n+1)]
        
        def calculate_overlap(reference_ngrams: List[str], 
                            candidate_ngrams: List[str]) -> float:
            if not reference_ngrams:
                return 0.0
            ref_set = set(reference_ngrams)
            cand_set = set(candidate_ngrams)
            overlap = len(ref_set & cand_set)
            return overlap / len(ref_set) if ref_set else 0.0
        
        reference = self._clean_text(reference)
        candidate = self._clean_text(candidate)
        
        scores = {}
        for n in [1, 2, 3]:
            ref_ngrams = get_ngrams(reference, n)
            cand_ngrams = get_ngrams(candidate, n)
            scores[f'rouge-{n}'] = calculate_overlap(ref_ngrams, cand_ngrams)
        
        return scores
    
    def bert_score(self, reference: str, candidate: str) -> float:
        """Calculate semantic similarity using sentence embeddings."""
        if not self.similarity_model:
            # Fallback to lexical if model not available
            return self.rouge_scores(reference, candidate)['rouge-2']
        
        try:
            ref_embedding = self.similarity_model.encode([reference])
            cand_embedding = self.similarity_model.encode([candidate])
            
            similarity = torch.cosine_similarity(
                ref_embedding, cand_embedding, dim=1
            ).item()
            return max(0.0, min(1.0, similarity))  # Clamp to [0,1]
        except Exception as e:
            print(f"BERTScore calculation failed: {e}")
            return 0.0
    
    def factual_consistency(self, context: str, claim: str) -> float:
        """Check if a claim is supported by the context using NLI."""
        if not self.factuality_model:
            return 1.0  # Default to consistent if model unavailable
        
        try:
            # Format for NLI model
            premise = f"Context: {context}"
            hypothesis = f"Claim: {claim}"
            
            result = self.factuality_model(f"{premise} [SEP] {hypothesis}")
            label = result[0]['label']
            score = result[0]['score']
            
            # Map labels to consistency scores
            label_mapping = {
                'ENTAILMENT': 1.0,
                'CONTRADICTION': 0.0,
                'NEUTRAL': 0.5
            }
            return label_mapping.get(label, 0.5) * score
            
        except Exception as e:
            print(f"Factual consistency check failed: {e}")
            return 0.5  # Conservative default
    
    def _clean_text(self, text: str) -> str:
        """Normalize text for comparison."""
        text = re.sub(r'[^\w\s]', '', text.lower())
        return ' '.join(text.split())
    
    def evaluate_generation(self, reference: str, candidate: str, 
                          context: str = "") -> Dict[str, Any]:
        """Comprehensive generation evaluation."""
        scores = {}
        
        # Lexical metrics
        scores.update(self.rouge_scores(reference, candidate))
        
        # Semantic metrics
        if self.use_semantic:
            scores['bert_score'] = self.bert_score(reference, candidate)
        
        # Factual consistency
        if context:
            # Extract claims from candidate (simplified)
            claims = self._extract_claims(candidate)
            consistency_scores = []
            for claim in claims:
                consistency_scores.append(
                    self.factual_consistency(context, claim))
            scores['factual_consistency'] = (
                sum(consistency_scores) / len(consistency_scores) 
                if consistency_scores else 0.0
            )
        
        return scores
    
    def _extract_claims(self, text: str) -> List[str]:
        """Extract factual claims from generated text."""
        # Simple sentence-based claim extraction
        sentences = re.split(r'[.!?]+', text)
        return [s.strip() for s in sentences if len(s.strip()) > 10]
```

### Composite Scoring System with Weighted Metrics

```python
from typing import Dict, List, Tuple
import json

class RAGEvaluator:
    """End-to-end RAG evaluation with configurable metric weighting."""
    
    def __init__(self, config_path: Optional[str] = None):
        self.retrieval_evaluator = RetrievalEvaluator()
        self.generation_evaluator = GenerationEvaluator()
        
        # Default weights - can be customized per use case
        self.weights = {
            'retrieval': 0.4,
            'generation': 0.3,
            'end_to_end': 0.3
        }
        
        if config_path:
            self._load_config(config_path)
    
    def _load_config(self, config_path: str):
        """Load evaluation configuration from JSON file."""
        with open(config_path, 'r') as f:
            config = json.load(f)
            self.weights.update(config.get('weights', {}))
    
    def calculate_composite_score(self, retrieval_metrics: Dict[str, float],
                                generation_metrics: Dict[str, float],
                                e2e_metrics: Dict[str, float]) -> float:
        """Calculate weighted composite score."""
        # Normalize and weight retrieval metrics
        retrieval_score = self._normalize_score(retrieval_metrics)
        generation_score = self._normalize_score(generation_metrics)
        e2e_score = self._normalize_score(e2e_metrics)
        
        composite = (
            self.weights['retrieval'] * retrieval_score +
            self.weights['generation'] * generation_score +
            self.weights['end_to_end'] * e2e_score
        )
        
        return composite
    
    def _normalize_score(self, metrics: Dict[str, float]) -> float:
        """Normalize metrics to 0-1 scale with appropriate weighting."""
        if not metrics:
            return 0.0
        
        # Different metrics have different importance
        metric_importance = {
            'precision@10': 1.0,
            'recall@10': 1.0,
            'mrr': 1.5,  # MRR is often more important
            'ndcg@10': 1.2,
            'rouge-2': 0.8,
            'bert_score': 1.0,
            'factual_consistency': 2.0  # Critical for factual accuracy
        }
        
        weighted_sum = 0.0
        total_weight = 0.0
        
        for metric, value in metrics.items():
            weight = metric_importance.get(metric, 1.0)
            weighted_sum += value * weight
            total_weight += weight
        
        return weighted_sum / total_weight if total_weight > 0 else 0.0
    
    def evaluate_rag_system(self, test_cases: List[Dict[str, Any]]) -> Dict[str, Any]:
        """Evaluate complete RAG system on test cases."""
        all_scores = {
            'retrieval': [],
            'generation': [],
            'e2e': [],
            'composite':
