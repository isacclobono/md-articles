# Java News Roundup: Grails 8, Open Liberty, GlassFish, Infinispan, LangChain4j, Spock

## Introduction

If you’ve been watching the JVM ecosystem closely, you’ve felt a subtle but seismic shift over the last eighteen months. The industry isn't chasing "cloud-native" as a buzzword anymore—we're codifying it into baseline expectations. This roundup isn't just a list of version bumps; it’s a snapshot of the **Cloud-Native Java Contract** solidifying in real time: Native Image first-class support, Virtual Threads as the default concurrency primitive, Jakarta EE 11 as the portable runtime layer, and GenAI integration that doesn't require a PhD or vendor lock-in.

The cluster of releases hitting GA and RC channels right now—Grails 8, Open Liberty 24.0.0.3 / GlassFish 7.0.12, Infinispan 15, LangChain4j 0.30+, Spock 2.3—reads like a checklist for the platform we’ve been architecting for five years. The "boring" stability of these releases is exactly the strategic advantage we’ve been waiting for.

## Why This Matters

You’re likely planning Q3/Q4 roadmaps. The decisions you make *now* on framework baseline, runtime target, and data grid strategy will dictate your operational burden for the next 3–5 years.

*   **Supply Chain & LTS Gravity:** Grails 8 finally lands on Micronaut 4.x, Groovy 4, and Gradle 8. This isn't cosmetic—it aligns your full-stack framework with the same LTS cadence and GraalVM Native Image maturity as Spring Boot 3.x, but with a fraction of the startup overhead.
*   **Runtime Portability is Non-Negotiable:** Open Liberty’s "Zero-Migration" kernel and GlassFish’s RI purity give you two valid, spec-compliant paths for Jakarta EE 11 (CDI 4.0, Faces 4.0, Concurrency 3.0). The choice is no longer "which spec works," but "which operational model fits my platform team."
*   **Data Gravity Meets Loom:** Infinispan 15 isn't just a faster cache. By embracing `StructuredTaskScope` and `ScopedValue`, it turns the cache-aside pattern from a callback-hell liability into structured, observable code that plays nice with virtual threads.
*   **AI Without the Vendor Tax:** LangChain4j 0.30+ provides a *real* abstraction layer—unified chat models, embedding stores, and RAG pipelines—so swapping OpenAI for a local Llama 3 on Ollama or a Vertex AI endpoint is a config change, not a rewrite.
*   **Testing as Documentation:** Spock 2.3 on Groovy 4 brings `groovy-transform` compilation avoidance and better IntelliJ support. If you’re still writing JUnit 5 tests in Java for Groovy/Kotlin codebases, you’re paying a syntax tax you don't need to.

## Core Concepts

### 1. Grails 8: The Micronaut Foundation Maturation
Grails 8 isn't a rewrite; it's a **re-platforming**. The core IoC container is now Micronaut 4’s compile-time DI engine.
*   **AOT Compilation:** Bean definitions, URL mappings, and GORM entity metadata are processed at compile time. `grails-native-image` plugin registers `RuntimeHints` automatically.
*   **Groovy 4 + `@GrailsCompileStatic`:** The default for artifacts. Dynamic dispatch is opt-in (`@CompileDynamic`), enabling aggressive inlining in Native Image.
*   **GORM 8 Breaking Changes:** `findAllBy*` dynamic finders now return `List` not `ArrayList`. `deleteAll()` requires explicit transaction boundary. `grails-plugin-*` namespace is purged—plugins are standard JARs with `grails-plugin` capability in `build.gradle`.

### 2. Open Liberty vs. GlassFish: Operational Philosophy
| Dimension | Open Liberty 24 | GlassFish 7 |
| :--- | :--- | :--- |
| **Kernel** | Feature-based, OSGi-free, dynamic updates | Modular (HK2), RI reference architecture |
| **Startup (Cold)** | ~0.8s (thin server) / ~50ms (InstantOn/CRC) | ~3.2s |
| **Memory (Idle)** | ~35MB heap (minimal features) | ~120MB heap |
| **Jakarta EE 11** | Full Platform certified | Full Platform certified (RI) |
| **Native Image** | `instanton` (Checkpoint/Restore) + GraalVM | GraalVM Reachability Metadata (experimental) |
| **Best For** | Cloud-native microservices, K8s, CRC dev loops | Spec validation, complex EE monoliths, Faces-heavy apps |

**The Portable Contract:** MicroProfile Config 3.0 (`ConfigSource` SPI) and REST Client 3.0 are identical on both. Your business logic sees zero vendor API.

### 3. Infinispan 15: Loom-Native Data Grid
*   **Virtual Thread Affinity:** `RemoteCacheManager` operations park virtual threads, not platform threads. Throughput scales to 10k+ concurrent cache ops on 2 CPU cores.
*   **Structured Concurrency:** `cache.getAsync(key)` returns a `CompletableFuture` that integrates with `StructuredTaskScope.ShutdownOnFailure()`. Cache misses, timeouts, and network partitions become structured exceptions, not leaked futures.
*   **Server-Side Scripting:** Moved from Nashorn to **GraalVM Polyglot API (JavaScript/Python)** with strict sandboxing (CPU/Memory limits per script). ProtoStream serialization is now the default wire format—no more Java serialization attack surface.

### 4. LangChain4j: The `AiServices` Abstraction
The killer feature in 0.30+ is `AiServices.create(Assistant.class, chatModel, retrievalAugmentor)`. You define a Java interface:
```java
interface Assistant {
    String chat(String userMessage);
    @SystemMessage("You are a SQL expert. Generate Postgres SQL.")
    String generateSql(@UserMessage String instruction);
}
```
The framework implements the proxy, handles prompt templating, RAG retrieval (via `ContentRetriever`), and tool calling (function calling) via reflection on default methods. Zero boilerplate.

### 5. Spock 2.3: Groovy 4 Alignment
*   **Compilation Avoidance:** Uses Groovy 4’s `groovy-transform` AST mechanism. Changing a test method body doesn't recompile the production class.
*   **Data Tables:** `@Unroll` with `|_` placeholder for ignored columns keeps tables readable.
*   **Mocking:** `Mock()` now uses `ByteBuddy` under the hood for final classes (configurable), closing the gap with Mockito inline mocking.

## Examples & Code Walkthrough

### 1. Grails 8: Centralized GraalVM Native Image Hints
Stop scattering `RuntimeHintsRegistrar` implementations across plugins. Centralize them in a `@Configuration` class that activates only when the GraalVM `NativeImage` class is present.

**`src/main/groovy/com/arch/boot/GrailsNativeConfiguration.groovy`**
```groovy
package com.arch.boot

import grails.compiler.GrailsCompileStatic
import groovy.transform.CompileStatic
import org.grails.config.ConfigProperty
import org.springframework.context.annotation.Configuration
import org.springframework.core.env.Environment
import org.springframework.aot.hint.RuntimeHints
import org.springframework.aot.hint.RuntimeHintsRegistrar
import org.springframework.aot.hint.MemberCategory
import org.springframework.aot.hint.TypeReference
import org.springframework.util.ClassUtils

// CompileStatic is mandatory for AOT processing to see this class
@GrailsCompileStatic
@Configuration
class GrailsNativeConfiguration implements EnvironmentAware, RuntimeHintsRegistrar {

    @ConfigProperty(name = 'grails.native.aot.enabled', defaultValue = 'true')
    boolean aotEnabled

    private Environment springEnv

    @Override
    void setEnvironment(Environment environment) {
        this.springEnv = environment
    }

    // Called by Spring AOT engine during build
    @Override
    void registerHints(RuntimeHints hints, ClassLoader classLoader) {
        if (!aotEnabled || !ClassUtils.isPresent("org.graalvm.nativeimage.ImageInfo", classLoader)) {
            return // Not a native build, skip expensive hint registration
        }

        registerGormHints(hints, classLoader)
        registerControllerHints(hints, classLoader)
        registerPluginReflectionHints(hints, classLoader)
    }

    private void registerGormHints(RuntimeHints hints, ClassLoader classLoader) {
        // GORM dynamic finders invoke constructors via reflection heavily
        // Register the domain class prefix pattern used by Grails artefact handling
        hints.reflection().registerType(
            TypeReference.of("org.grails.datastore.gorm.GormEntity"),
            MemberCategory.INVOKE_DECLARED_CONSTRUCTORS,
            MemberCategory.INVOKE_DECLARED_METHODS,
            MemberCategory.INVOKE_PUBLIC_CONSTRUCTORS,
            MemberCategory.INVOKE_PUBLIC_METHODS
        )

        // Serialization hints for session replication / clustering
        hints.serialization().registerType("org.grails.datastore.gorm.GormEntity")
        hints.serialization().registerType("org.grails.datastore.mapping.model.PersistentEntity")
    }

    private void registerControllerHints(RuntimeHints hints, ClassLoader classLoader) {
        // Controllers are instantiated by Micronaut/Grails runtime reflectively
        // Scan for @Controller classes? Too heavy. Register the base artefact handler.
        hints.reflection().registerType(
            TypeReference.of("org.grails.web.servlet.mvc.GrailsController"),
            MemberCategory.INVOKE_DECLARED_CONSTRUCTORS
        )
    }

    private void registerPluginReflectionHints(RuntimeHints hints, ClassLoader classLoader) {
        // Example: Quartz plugin uses reflection for Job classes
        if (ClassUtils.isPresent("org.quartz.Job", classLoader)) {
            hints.reflection().registerType(
                TypeReference.of("org.quartz.Job"),
                MemberCategory.INVOKE_DECLARED_METHODS
            )
        }
    }
}
```
**Why this works:** Implements `RuntimeHintsRegistrar` directly on the `@Configuration` bean. Spring AOT picks it up automatically during `grails compile` (AOT phase). The `ClassUtils.isPresent` guard ensures zero overhead in JIT mode.

### 2. Portable MicroProfile Config: HashiCorp Vault Backed
