# 🚀 ScopeSaathi AI: Your AI-Powered Freelance Project Scope Assistant

## Introduction  
A freelance designer once spent three days chasing vague client emails that promised “a modern landing page.” By the end of the week, the estimate was half a million dollars because the brief never defined deliverables, timeline, or revision limits. That experience illustrates the hidden cost of fuzzy scopes: lost time, eroded margins, and frustrated partners. ScopeSaathi AI was built to turn a raw, unstructured brief into a concrete, billable specification automatically, giving teams a reliable copilot that reduces ambiguity before labor begins.

## Why This Matters  
Unclear project boundaries are a recurring source of revenue leakage. Industry studies consistently show that scope creep can shave 15‑20 % off total project profit when estimates rely solely on word counts. Static templates and manual checklists fail to adapt to evolving client needs, while basic LLM integrations often return jargon‑laden prose that requires extensive editing. An architecture that marries structured data ingestion, prompt engineering, and low‑latency generation gives developers a repeatable pipeline that preserves both speed and accuracy.

## How It Works  
The assistant follows a four‑stage flow:

1. **Ingestion** – The front‑end captures file uploads, text notes, and rough sketches through a responsive form.  
2. **Contextualisation** – A lightweight pre‑processor normalises the input, extracts key terms, and formats a JSON payload (`ScopeRequest`).  
3. **Generation** – The backend routes the payload to a dedicated service that builds a prompt, dispatches it to an LLM host, and parses the result back into a `ScopeResult`.  
4. **Preview** – Using a WebSocket channel, the client receives incremental markdown so the designer sees the evolving scope in real time.

Below is the high‑level Mermaid diagram that visualises this pipeline.

```mermaid
flowchart TD
    A[Freelancer UI] --> B[WebSocket Preview]
    C[API Gateway] --> D[Scope Generation Service]
    D --> E[LLM Host (Ollama/OpenAI)]
    E --> F[Scope Result]
    F --> G[Final Response]
```

Each component is responsible for a single concern, making the system easier to test, monitor, and extend.

## Core Concepts  

- **ScopeRequest** – A typed container holding raw text, attached files, and any auxiliary metadata such as preferred format or deadline.  
- **ScopeResult** – Structured output containing objective, deliverables, timeline, assumptions, and a checklist of acceptance criteria.  
- **PromptEngine** – A Jinja‑style builder that injects dynamic placeholders (e.g., `{client_name}`, `{deadline}`) while preserving version control of template snippets.  
- **LivePreview** – A React component that subscribes to a WebSocket stream, rendering each chunk of the generated markdown instantly, which improves perceived responsiveness.  
- **GeneratorService** – Orchestrates the prompt creation, LLM inference, and post‑processing (validation, formatting) steps. It also handles fallback paths when the external model is unavailable.

These primitives keep the codebase decoupled, allowing independent teams to own the UI layer, the ML integration, or the database schema without stepping on each other’s toes.

## Examples & Code Walkthrough  

### Front‑End – Custom Hook for Form Management  

```tsx
import { useState, useRef, useCallback } from "react";
import { FormatContext } from "react-hot-form";

// Type definitions
interface ScopeField {
  id: string;
  label: string;
  type: "text" | "select" | "textarea" | "file";
}

const initialFields: ScopeField[] = [
  { id: "client_name", label: "Client Name", type: "text" },
  { id: "deadline", label: "Target Delivery Date", type: "date" },
  { id: "budget", label: "Estimated Budget ($)", type: "number" },
];

/**
 * Manages the scope form state, validation, and live WebSocket connection.
 */
export const useScopeForm = () => {
  const [fields, setFields] = useState<ScopeField[]>(initialFields);
  const [errors, setErrors] = useState<Record<string, string>>({});
  const wsRef = useRef<WebSocket | null>(null);

  // Build a controlled form using react‑hot‑form's context
  const hotForm = new FormatContext(
    fields,
    (value) => ({ values: { ...fields, [value]: value } }),
    (error) => console.warn(`Validation failed for ${error}`)
  );

  // Validate on change for each field
  const validate = (name: string) => {
    if (name === "client_name" && !fields.find(f => f.id === name)) return "";
    if (name === "deadline" && !fields.find(f => f.id === name)) return "";
    if (name === "budget" && fields.find(f => f.id === name)?.type !== "number") return "";
    return "";
  };

  // Open a persistent WebSocket for server‑side preview streaming
  const connectWebSocket = useCallback(() => {
    try {
      wsRef.current = new WebSocket("wss://localhost:3001/preview");
      wsRef.current!.readyState === WebSocket.OPEN
        ? wsRef.current!.send(JSON.stringify({ action: "subscribe", projectId: "demo" }))
    } catch (err) {
      console.error("WebSocket init failed:", err);
    }
  }, []);

  const submitScope = useCallback(
    async (data: Partial<ScopeRequest>) => {
      // Run client‑side validation first
      Object.keys(data).forEach(key => {
        if (!fields.some(f => f.id === key) || !validate(key)) {
          setErrors(prev => ({ ...prev, [key]: "Missing or invalid input" }));
          return;
        }
      });

      // Send payload to the async endpoint
      await fetch("/api/scope", {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify(data),
      });
    },
    [fields, validate]
  );

  return {
    fields,
    errors,
    hotForm,
    connectWebSocket,
    submitScope,
    isConnected: !!wsRef.current?.readyState === WebSocket.OPEN,
  };
};
```

*Explanation*: The hook combines a declarative form library (`react-hot-form`) with a tiny WS manager. Validation runs locally before any round‑trip to the backend, guaranteeing a clean error surface for the designer.

### Backend – Scope Generation Service  

```ts
import express, { Request, Res, Router } from "express";
import { v4 as uuidv4 } from "uuid";
import { GenerateScope } from "./generator.service";

const app = express();
app.use(express.json());

/**
 * RESTful entry point for designers.
 * Endpoint: POST /api/scope
 * Body: ScopeRequest
 */
router.post("/scope", async (req: Request, res: Res) => {
  const { scopeData } = req.body;

  // Basic sanity check – reject empty requests early
  if (!scopeData || Object.keys(scopeData).length === 0) {
    return res.status(400).json({ error: "Missing required fields in ScopeRequest" });
  }

  // Delegate heavy lifting to the generator service
  const generator = new GenerateScope();
  let result: any;

  try {
    result = await generator.generate(scopeData);
    res.json(result);
  } catch (err) {
    // Log internally but expose a safe message to the user
    console.error("Scope generation failed:", err);
    res.status(500).json({ error: "Internal processing error" });
  }
});

module.exports = app;
```

### Generator Service – Core Logic  

```ts
// generator.service.ts
import { v4 as uuidv4 } from "uuid";

// Domain types
export interface ScopeRequest {
  clientName?: string;
  deadline?: string;
  budget?: number;
  extraNotes?: string;
}
export interface ScopeResult {
  id: string;
  projectId: string;
  objective: string;
  deliverables: string[];
  timeline: string;
  assumptions: string[];
  checklist: string[];
}

/**
 * Builds a prompt tailored to the incoming brief.
 * Uses Jinja‑style placeholders for dynamic injection.
 */
function buildPrompt(req: ScopeRequest): string {
  const client = req.clientName ?? "the client";
  const deadline = req.deadline ?? "within two weeks";
  const budgetStr = req.budget ?? "unspecified";

  return `
Objective: Deliver a [client] project titled "${client}" by ${deadline}.

Deliverables:
- Design system mockups
- High‑fidelity wireframes
- Interaction prototype (Figma or Sketch export)

Timeline:
- Discovery (1 day)
- Design iteration (3 days)
- Prototype handoff (1 day)

Assumptions:
- All assets will be provided in PNG/PDF format.
- Any additional specifications should be added as separate notes.

Please answer concisely, respecting the word limit.
`;
}

/**
 * Generates a formal scope document using an LLM.
 * In a production deployment you would swap the placeholder above for a
 * real call to Ollama or the OpenAI API.
 */
export class GenerateScope {
  private llmUrl: string;
  constructor() {
    // Placeholder URL – replace with actual endpoint during rollout
    this.llmUrl = process.env.LLM_ENDPOINT ?? "http://localhost:8000/v1/generation";
  }

  async generate(request: ScopeRequest): Promise<ScopeResult> {
    const prompt = buildPrompt(request);

    // Simulated LLM call – replace with real HTTP request in production
    const response = await fetch(this.llmUrl, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({
        model: "gpt-4",
        messages: [
          { role: "system", content: "You are a helpful assistant.",
            }],
          { role: "user", content: prompt },
        ],
      }),
    });

    if (!response.ok) {
      throw new Error(`LLM returned status ${response.status}`);
    }
    const llmPayload = await response.json();

    // Parse the model’s reply – expects a JSON object with "output" field
    const out = llmPayload.output ?? {};

    // Transform raw LLM answer into our domain schema
    const objective = out.objective || "Create a comprehensive project scope.";
    const deliverables = out.deliverables || ["wireframes", "prototype", "specification"];
    const timeline = out.timeline || "2‑week delivery cycle";
    const assumptions = out.assumptions?.join(", ") ?? [];
    const checklist = out.checklist?.join(", ") ?? "";

    return {
      id: uuidv4(),
      projectId: request.projectId ?? "unknown",
      objective,
      deliverables,
      timeline,
      assumptions,
      checklist,
    };
  }
}
```

*Key points*: The generator encapsulates everything from prompt construction to post‑processing. By keeping the LLM call abstract behind the `GenerateScope` class, swapping models or adding fine‑tuning becomes a one‑line change.

### Live Preview Component  

```tsx
import React, { useEffect, useRef } from "react";
import { useScopeForm } from "./useScopeForm";

/**
 * Renders the generated scope as it arrives over a WebSocket.
 * Each chunk is rendered immediately, providing a smooth reading experience.
 */
export const ScopePreview = ({ projectId }: { projectId: string }) => {
  const { isConnected, submitScope, errors } = useScopeForm();
  const previewRef = useRef<HTMLDivElement>(null);

  useEffect(() => {
    if (isConnected && previewRef.current) {
      const ws = new WebSocket(`wss://localhost:3001/preview`);
      ws.onmessage = (event) => {
        const msg = JSON.parse(event.data);
        if (msg.type === "scopeChunk") {
          // Insert paragraph into the DOM
          const fragment = document.createDocumentFragment();
          fragment.innerHTML = `<h3>Section ${msg.section}</h3><p>${msg.content}</p>`;
          previewRef.current.appendChild(fragment);
        }
      };
      // Subscribe to the stream
      ws.send(JSON.stringify({ action: "subscribe", projectId }));
    }
  }, [isConnected, projectId]);

  return (
    <div className="border rounded-lg p-6 max-w-4xl">
      <h2>Generated Scope</h2>
      {errors[projectId] && (
        <p className="text-red-600">❌ {errors[projectId]}</p>
      )}
      <div ref={previewRef} className="mt-4 overflow-auto h-[600px]"></div>
    </div>
  );
};
```
